# PartyLinePager for TrueNAS

Multi-protocol room pager with Tor, I2P, and Reticulum party
lines across nine chat network adapters.

Open a room on one chat network, and everyone who subscribed on
any chat network gets a way into it.

## Configuration

After installation, open the web terminal at port 7681 to run the
setup wizard. Adapter credentials (Telegram, Discord, Matrix, etc.)
can be passed as additional environment variables.
